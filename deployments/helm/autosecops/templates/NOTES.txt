AutoSecOps {{ .Chart.AppVersion }} is deployed as release "{{ .Release.Name }}" in namespace "{{ .Release.Namespace }}".

Public URL: {{ include "autosecops.publicAppUrl" . }}

1. Watch the rollout:

   kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} -w

{{- if .Values.migrations.enabled }}

   Migrations run in the {{ include "autosecops.migrationsJobName" . }} Job:
   kubectl -n {{ .Release.Namespace }} logs job/{{ include "autosecops.migrationsJobName" . }}
{{- end }}

2. Check the API without an ingress:

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "autosecops.componentName" (dict "root" . "component" "api") }} 8000:{{ .Values.api.service.port }}
   curl http://localhost:8000/health

{{- if .Values.ingress.enabled }}

3. Open https://{{ .Values.ingress.host }} once DNS points at your ingress controller.
{{- else }}

3. Expose the UI and API with `ingress.enabled=true`, or put your own proxy in
   front of the {{ include "autosecops.componentName" (dict "root" . "component" "ui") }} (/) and {{ include "autosecops.componentName" (dict "root" . "component" "api") }} (/api) services.
{{- end }}

{{- if and (not .Values.externalPostgres.auth.existingSecret) (not .Values.externalPostgres.auth.runtimePassword) }}

WARNING: externalPostgres.auth.runtimePassword is empty, so the services connect
as the database owner and tenant row-level security is inactive. Set it (or the
`{{ .Values.externalPostgres.auth.runtimePasswordKey }}` key of an existing Secret) and upgrade.
{{- end }}

{{- if not .Values.autosecops.temporal.payloadEncryption.enabled }}

WARNING: autosecops.temporal.payloadEncryption.enabled is false, so workflow
inputs, results, and failures are stored in plaintext in Temporal's database.
Add a keyring and enable it: https://docs.singularityrd.com/self-hosting/security#temporal-payload-encryption
{{- end }}

Sign in first as {{ .Values.autosecops.auth.superadminEmail }} to become superadmin.
{{- else }}

WARNING: autosecops.auth.superadminEmail is empty. Nobody can register until you set it.
{{- end }}

Each plan includes every entitlement of the plans before it.
A [license key](/self-hosting/license) grants exactly the entitlements it lists, so a license can also add single entitlements to a plan.
Community is the free feature set and needs no license.
To buy or change a plan, contact [info@singularityrd.com](mailto:info@singularityrd.com).

Enterprise includes every entitlement, including ones added in later releases.
MSSP adds the `multi_tenant` deployment grant to Enterprise.
A Pilot license includes the Enterprise entitlements for 60 days.

| Plan | Default term |

## Default limits

No plan sets a limit by default.
A license sets limits per contract; a limit the license does not set is unlimited.
See [License limits](/self-hosting/license#license-limits) for how AutoSecOps enforces them.

| Limit | Key | Default |
| :---- | :-- | :------ |
| Active users | `max_users` | Unlimited |
| Workspaces | `max_workspaces` | Unlimited |
| Organizations | `max_organizations` | Unlimited |
| Concurrent workflow runs | `max_concurrent_workflows` | Unlimited |
| Concurrent actions | `max_concurrent_actions` | Unlimited |
| Action executions per workflow run | `max_action_executions_per_workflow` | Unlimited |

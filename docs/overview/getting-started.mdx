The recommended way to get started is to connect your coding agent — Claude Code, OpenAI Codex, GitHub Copilot, or Cursor — to the AutoSecOps MCP server.
This works with your self-hosted AutoSecOps instance.

## Connect MCP

Deploy AutoSecOps first (see [Self-host](#self-host)), then connect your agent to its MCP endpoint.

## Self-host

Choose a deployment method:

- [Docker Compose](/self-hosting/docker-compose): Run every service on a single host. This is the fastest way to self-host.
- [AWS ECS Fargate](/self-hosting/aws-fargate): Deploy to your own AWS account with Terraform.
- [Kubernetes](/self-hosting/kubernetes): Install the Helm chart on EKS, GKE, or any conformant cluster.
- [Air-gapped installation](/self-hosting/air-gapped): Install on Docker Compose or Kubernetes with no internet access.

See [Architecture](/self-hosting/architecture) for how the services fit together.

### Docker Compose quickstart

Follow the full [Docker Compose guide](/self-hosting/docker-compose) or run the commands below.

```bash
# Extract the install files from the AutoSecOps image
docker pull ghcr.io/singularityrd/autosecops:1.0.0
id=$(docker create ghcr.io/singularityrd/autosecops:1.0.0)
docker cp "$id":/opt/autosecops/install/. .
docker rm "$id"

# Setup environment variables and secrets
chmod +x env.sh && ./env.sh

# Start AutoSecOps
docker compose up -d
```

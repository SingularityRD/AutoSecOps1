## Check RoboDR action policy

Action ID: `tools.robodr.check_action_policy`

Check a robot action request against the SOC-side rules before it is sent: catalog action, approvals (single or two-person, never the requester), and morphology (no safe_pause, request_safe_state or rollback_config on a humanoid; no rollback_config on a quadruped).

Reference: [https://docs.singularityrd.com/integrations/robodr-tools](https://docs.singularityrd.com/integrations/robodr-tools)

</ParamField>

## Verify RoboDR finding signature
